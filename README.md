# 3D-parametric-curve-visualizer
Python program for visualizing 3D parametric curves from custom equations using NumPy and Matplotlib.

## Example

Example input:

x(t) = `3*np.cos(t)`  
y(t) = `3*np.sin(t)`  
z(t) = `t`

This produces a spiral curve in 3D space.

This produces a spiral curve in 3D space.

## How to Run

Install the required libraries:

pip install numpy matplotlib

Run the program:

python main.py

Then enter equations for x(t), y(t), and z(t).

Example:

Enter x(t): `3*np.cos(t)`  
Enter y(t): `3*np.sin(t)`  
Enter z(t): `t**2`

This produces a spiral curve in 3D space.
